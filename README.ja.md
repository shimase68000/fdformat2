# FDFORMAT2

[English](README.md) | [日本語](README.ja.md)

FDFORMAT2 は X68000 用の 2HD フロッピーディスクフォーマッタです。\
挿入されたディスクに対して、物理フォーマット、及び、論理フォーマットを行います。\
物理フォーマットのみ・論理フォーマットのみの指定も可能です。

---

## Features

* 最大 4 台のフロッピーディスクドライブに対応\
  （内蔵 2 台 + 外付け最大 2 台）

* ディスクの挿入を自動検知

* フォーマット開始前の確認あり（`Y` → `ENTER`）

* フォーマット完了後にディスクを自動排出

* 各ドライブのフォーマットを並行処理

* フォーマット完了した枚数の表示（ドライブごと・合計）

* セクタスライドに対応（ドライブごとに異なるスライド値を指定可能）

* ユーザー確認なしの動作モード（**FORCE MODE**）も選択可能

---

## Usage

```
usage: fdformat2 [switch]
switch:  -p            physical format only
         -l            logical format only
         -s<0-7>...    sector slide value (default:2)
         -force        force mode (skip confirmation)
```

1. `fdformat2` を起動する
2. 空いているドライブにディスクを挿入する
3. 確認に `Y` → `ENTER` で応答する
4. フォーマットが完了すると自動排出される
5. 次のディスクを挿入して続ける

確認の待ち状態でも、他のドライブで進行中の処理を止めません。

詳細は同梱の説明書を参照してください。

## 終了操作

終了は `ESC` から始めます。

| 操作 | 動作 |
|---|---|
| `ESC` | 新規ディスクの受付を停止し、進行中のフォーマット完了後に終了する |
| `ESC` → `Q` | 進行中のフォーマットを中断して終了する（確認あり） |

**FORCE MODE** では、`ESC` → `Q` の確認を行いません。

---

## セクタスライド

セクタスライドは、セクタの開始位置をずらしながらフォーマットすることにより、\
主に連続した領域に対するディスクアクセスを高速化する手法です。

既定値は 2 です。`-s` で変更できます。

```
fdformat2 -s3       全ドライブに 3 を指定
fdformat2 -s0123    ドライブ 0,1,2,3 に順に指定
```

`-s0` はスライドなし（ノーマルフォーマット）になります。

---

## 作成されるディスク

2HD（1024 バイト × 8 セクタ × 77 シリンダ × 2 面）としてフォーマットします。

論理フォーマットでは、BPB、FAT、ルートディレクトリ、および最小限の IPL を書き込みます。

ボリュームシリアル番号を記録します。生成規則は moformat と共通です。

作成したディスクは PC98系 2HD (1.2MB FDD) の MS-DOS からも読み書きできます。

---

## Technical Notes

Human68k の DOS / IOCS コールを使用しています。

* メディア状態の検出
* 物理フォーマット
* 論理フォーマットの書き込み
* ディスクの排出
* 進捗表示

ドライブごとに状態を持ち、メインループでポーリングして並行処理します。

---

## Notes

* フロッピーディスクドライブを備えた X68000 が対象です
* 動作はドライブ構成に依存する場合があります
